📖 Guia de Configuração ▼
Campos comuns
Webhook URL URL da sua aplicação que receberá os payloads enviados pelo mock quando uma mensagem for enviada. http://csa-web-1:8000/api/v1/whatsapp/webhook/
Nome do contato Nome fictício do usuário simulado. Aparece no cabeçalho do chat e em profile.name nos payloads.
WhatsApp
Número (E.164) Identificador do contato — somente dígitos, sem +. Usado como wa_id no payload. 5586999990000
Phone Number ID ID do número cadastrado no painel Meta. Vai em metadata.phone_number_id — seu backend usa esse valor para identificar o canal. Copie do model Canal no admin do CSA. 102938475610293
Instagram
IGSID Identificador numérico do usuário no Instagram. Simula o ID real retornado pela API do Meta. 123456789
URLs geradas automaticamente
URL de Callback Registre como Callback URL no painel Meta. O mock recebe os payloads e os encaminha ao seu Webhook URL.
URL de Verificação Usada para verificar o webhook no Meta. Responde ao hub challenge com o hub.verify_token.
Credenciais do servidor
Verify Token Definido via VERIFY_TOKEN. Use o mesmo valor ao configurar o webhook no Meta.
App Secret Definido via APP_SECRET. Gera a assinatura X-Hub-Signature-256 em cada requisição.
Fluxo: configure os campos → salve → copie a URL de Callback para o Meta → envie mensagens pelo chat para simular um usuário real chegando no seu webhook.
